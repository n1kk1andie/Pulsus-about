How the brief is built

Judgement you can check.

Patent pending

Every reading in the brief comes from fixed rules over your own systems' data. The same data always gives the same answer, so any figure can be traced back and re-derived.

  1. 01

    Read

    Pulsus reads each system's own data and changes nothing in it. A system that can't be reached is reported as a blind spot, never quietly left out.

  2. 02

    Judge

    Written rules, not guesswork: spot the trend, weigh it, rank what matters. Thresholds for "healthy" and "critical" are set by your institution.

  3. 03

    Connect

    When the same branch or unit is flagged by two or more systems, it surfaces as one issue, not scattered alerts in separate reports.

  4. 04

    Phrase

    AI only rewords what the rules computed. If it adds any number that isn't in the facts, its version is rejected and the plain text stands.

    Grounded AI
  5. 05

    Learn

    Recommended actions are followed up. Pulsus measures whether each one actually helped, and weighs future advice by what worked.
