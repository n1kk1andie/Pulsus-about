Before anything is matched

Proved before it's used.

Every file is added up and checked against its own stated totals first. A file that doesn't prove is refused with the reason, so a wrong reconciliation is never produced quietly. Change an amount in the statement and watch.

The highlighted amount is editable.

Statement proof

  • Recognised from the file's own content: SWIFT MT940, MT942 and MT950, ISO 20022 camt.052, camt.053 and camt.054, and BAI2.
  • Card-scheme settlement reports and card-processor extracts read as they arrive.
  • Mastercard files: talk to us and we'll set them up with you.
  • Your own Excel or CSV layouts, taught once. If a sender changes the headings, Pulsus stops and asks you to teach the new layout.
  • An amount that can't be read is flagged, never taken as zero.
